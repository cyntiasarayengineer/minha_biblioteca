# 📚 Minha Biblioteca — Citações de Livros

Um aplicativo mobile simples, leve e eficiente desenvolvido em **Flutter**, criado para resolver uma necessidade real de organização de leitura e compartilhamento de citações.

---

## 💡 Sobre o Projeto

Como leitora assídua, eu costumava ter anotações de trechos e passagens marcantes espalhadas por diferentes lugares. O objetivo deste aplicativo foi **centralizar todas essas citações em um único lugar**, permitindo que eu possa buscar qualquer frase rapidamente por autor, livro ou palavra-chave.

Além da organização, o app conta com um **gerador de cards visuais** para exportar as frases formatadas e compartilhá-las diretamente no Instagram Stories ou WhatsApp em poucos cliques!

---

## ✨ Funcionalidades

- 📝 **Cadastro Rápido:** Salve citações com trecho, autor e título do livro.
- 🔍 **Busca em Tempo Real:** Pesquise instantaneamente por qualquer termo, livro ou autor.
- 🎨 **Gerador de Cards para Instagram:** Transforma o texto em um card estilizado e pronto para publicação.
- 📲 **Compartilhamento Nativo:** Integração direta com a gaveta de compartilhamento do Android (Instagram, WhatsApp, etc.).
- 💾 **Armazenamento Offline:** Dados salvos localmente no dispositivo para acesso rápido sem dependência de internet.

---

## 🛠️ Tecnologias Utilizadas

- **[Flutter](https://flutter.dev/):** Framework para desenvolvimento mobile cross-platform.
- **[Dart](https://dart.dev/):** Linguagem de programação principal.
- **[Hive](https://pub.dev/packages/hive):** Banco de dados NoSQL leve e ultrarrápido para persistência local.
- **[widgets_to_image](https://pub.dev/packages/widgets_to_image):** Conversão de widgets em imagens exportáveis em formato PNG.
- **[share_plus](https://pub.dev/packages/share_plus):** Acesso às APIs nativas de compartilhamento do sistema operacional.
